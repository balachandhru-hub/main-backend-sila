Do NOT blindly assume every API uses the same timestamp property.

Incremental Timestamp Source Field

and:

Incremental Filter Strategy.

For SAP OData:

generate safe OData $filter based on configured source timestamp

============================================================
29. CHECKPOINT PRINCIPLE
============================================================

NEVER advance extraction checkpoint before successful DB commit.

Correct:

LastSuccessfulRunAt = T1.

Start API extraction at T2.

Pull records changed since T1.

Map.

Validate.

UPSERT DB.

COMMIT.

Only after successful completion:

LastSuccessfulRunAt = extraction checkpoint.

If API fails:

DO NOT advance LastSuccessfulRunAt.

If DB fails:

DO NOT advance LastSuccessfulRunAt.
