============================================================
9. COMPANY CODE — MANDATORY
============================================================

CompanyCode is mandatory at PO Header level.

Store:

purchase_orders.company_code.


Do not automatically infer CompanyCode from Entity unless an explicit
Entity → CompanyCode mapping exists.


If CompanyCode conflicts with selected/configured Entity:

BLOCK:

COMPANY_CODE_ENTITY_MISMATCH.


Company Code will later be important for:

ERP routing

GRN posting

Invoice posting

financial validation.

36. RECEIVED / OPEN QTY ON INITIAL LOAD
============================================================

For initial PO master load:

ReceivedQuantity may be provided.


Default:

ReceivedQuantity = 0

if not supplied.


Validate:

ReceivedQuantity >= 0.


Normally:

ReceivedQuantity <= OrderedQuantity

unless configured legitimate over-receipt handling exists.


If OpenQuantity not provided:

calculate:

OpenQuantity =
OrderedQuantity - ReceivedQuantity.


If OpenQuantity provided:

validate consistency.


Do not blindly trust inconsistent spreadsheet quantities.
