============================================================
0. PRIMARY OBJECTIVE
============================================================

Transform the existing SILA ME Cloud application into a polished,
production-oriented enterprise hospitality application.

This task is primarily FRONTEND.

The existing SILA ME architecture must remain:

SILA ME Cloud
React + TypeScript + Vite
        ↓
Existing ASP.NET Core API
        ↓
PostgreSQL

SILA ME Mobile uses the SAME backend separately.

DO NOT:
- rebuild the backend
- replace ASP.NET Core
- create another database
- replace authentication
- replace existing Cloud cookie authentication
- modify Mobile
- break organization/unit/permission architecture
- rebuild working Invoice/GRN APIs
- create fake backend business transactions

Build a strong frontend framework that can support the complete
SILA ME product.

10. PERMISSION-AWARE NAVIGATION
============================================================

Navigation MUST respect current user's permissions.

Do not show admin menu to unauthorized users.

Do not rely ONLY on frontend hiding.

Backend remains authoritative.

Frontend behavior:

permission unavailable
→ hide navigation where appropriate

direct URL attempted
→ backend authorization
→ controlled Access Denied page.

Create reusable:

<PermissionGate>

and:

<RoutePermissionGuard>

Do not scatter permission checks throughout JSX.
