==================================================

The required architecture is:

SILA ME MOBILE
    |
    | Camera / Image / PDF
    |

    |
    +---- BUILT-IN OCR / DOCUMENT READER

    |          |      Supplier Name

    |          |      Supplier Invoice Number

26. PROVIDER ROUTING LOGIC
==================================================

Create:

IExtractionProviderResolver

Logic:

For incoming document:

1. Determine Organization
2. Determine Document Type
3. Look for ACTIVE extraction configuration
4. Match:
   organization + document type
5. Sort by priority
6. If valid active external provider exists:
      use configured external provider
7. Otherwise:
      use BUILT_IN OCR

CRITICAL:

No external configuration
must NEVER prevent invoice processing.

Fallback:

BUILT_IN OCR
