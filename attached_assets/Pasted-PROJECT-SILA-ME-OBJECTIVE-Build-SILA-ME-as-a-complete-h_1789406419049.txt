PROJECT: SILA ME

OBJECTIVE:
Build SILA ME as a complete hospitality Menu Engineering, Inventory, Store Operations, Receiving, Document Capture, Procurement Support, Approval, and Analytics platform using:

- SILA ME Cloud — React / Browser
- SILA ME Mobile — Expo / React Native
- SILA ME API — ASP.NET Core Web API
- PostgreSQL — shared database
- One shared backend for Cloud + Mobile

IMPORTANT:

Start from the already-proven basic foundation:
- Cloud preview works
- external Cloud URL works
- Mobile Expo app works
- Mobile can reach API
- Cloud login works
- Mobile login works
- one .NET backend
- one PostgreSQL database

DO NOT rebuild the foundation.

Add functionality gradually and preserve working login, routing, preview, Expo, API, and database behavior.
