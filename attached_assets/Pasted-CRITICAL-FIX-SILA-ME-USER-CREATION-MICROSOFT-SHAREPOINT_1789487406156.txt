CRITICAL FIX — SILA ME USER CREATION MICROSOFT SHAREPOINT AUTHENTICATION

CURRENT DEFECT:

Administration → Users → Add User

When Document Storage = Microsoft is selected, the application is NOT
triggering Microsoft authentication.

Therefore:

- SharePoint cannot be authenticated
- SharePoint URL/path cannot be validated
- SILA ME cannot confirm access to the destination
- Storage is being configured without proving that SILA ME can actually
  upload files there

THIS IS A BLOCKING DEFECT.

DO NOT mark Microsoft storage as configured based only on a typed URL.
